01 · THE PROBLEM

There is no hardcoded temperature anywhere in the detection path.

$ naive_alarm.py
if temp > 35: alert()
# screams all summer in a desert
# silent through a 12°C alpine excursion

WildSense keeps a rolling statistical baseline — an exponentially weighted mean and variance — for each channel, and flags a reading when it deviates from its own recent history.

Push a node's normal operating point from 20°C to 28°C and it fires once at the transition, then goes quiet — because 28°C is now simply what this place is like.

A statistical gate always sits in front of the classifier — a missing or broken model file degrades the event label, never the detection itself.

02 · HARDWARE

One sensor today. Built for more.

Adding a thermal camera or an air-quality pack is a config change, not a rewrite — the pipeline never imports a concrete sensor.

WIRING · 3-WIRE DHT22 MODULE
{{ row.from }} → {{ row.to }}
One-wire protocol, not I2C — nothing to find with i2cdetect, no address to set. The 3-wire module already carries its pull-up resistor.
TWO QUIRKS THE CODE HANDLES FOR YOU
Reads fail routinely
Bit-banged microsecond timing on a non-realtime OS means scheduling jitter corrupts the pulse train often. DHT22Sensor retries with a configurable budget and only gives up on the cycle — never the run.
Reads must be ≥ 2 seconds apart
The part needs that long to re-sample. min_interval_s enforces the gap and PollingPolicy clamps every risk level against it — no config value can out-run the hardware.

04 · THE AI ENGINE

Adaptive statistics, then a model.

Two stages with deliberately different jobs. Stage one decides if something is worth caring about; stage two names it — and only after measuring the detector fail without each of these three details.

WINSORISED BASELINE
An observation moves the baseline by at most clip_z std deviations. Without it, one 10°C spike inflated std by an order of magnitude.
4.19σ
measured std vs true noise of 0.2
DUAL-TIMESCALE BASELINE
A single fast EWMA absorbs a gradual ramp and stays blind to it. The slow baseline (~500-sample memory) is what makes drift detectable at all.
<1.0 z
31-sample ramp, fast baseline only
DEBOUNCED DETECTIONS
An ongoing condition is one event, not one per reading. Without a refractory period, a single episode re-fired on every cycle.
36 → 4
events emitted, 4 real episodes / 230s run

07 · CLOUD SYNC

Optional. Non-fatal by design.

A field node that dies because a bucket was misconfigured is worse than one that quietly keeps detecting. Uploads drain through a bounded queue on a daemon thread — a stalled network never blocks the sensor loop.
