03 / How it works

Four moves, and a sealed record of all of them.

01 / READ

Only the agent

The customer's words are context and never receive a verdict. Only the agent is being assessed.

02 / CLAIM

Exact quotes

Claims are stored as character positions in the real transcript. Nothing is paraphrased.

03 / RETRIEVE

Find the rule

Search the client's rulebook for the provision that governs that specific sentence.

04 / JUDGE

Rule from that text

A verdict, with the paragraph printed beside it so anyone can check it.
