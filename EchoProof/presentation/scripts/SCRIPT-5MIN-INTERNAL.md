# 5 minute internal

**This script is a pointer, not a duplicate.**

The canonical 5 minute script is
[../tomorrow/SCRIPT-5MIN-TOMORROW.md](../tomorrow/SCRIPT-5MIN-TOMORROW.md).
It is written word for word, on a 15 second clock, against
[../tomorrow/deck.html](../tomorrow/deck.html), and it is the one to rehearse.

Use this file only to adapt that script for a 5 minute slot that is **not**
tomorrow's AI Launchpad session.

## What stays identical

- The timing spine. Launch at 0:55, talk for 145 seconds, return at 3:25. Built on a measured 120.2 second run of `Furnished to a credit bureau before contact`.
- Every UI instruction, every button label, every claim id.
- The honest positioning block at 2:45. Never cut.
- Both fallbacks: run still going, and run failed.

## What changes by audience

**If the room is external rather than internal.** Replace the opening line.
Instead of "Voice AI agents are being put into regulated conversations right
now", open with the customer's own exposure: "You are about to put an agent in
front of customers in a regulated conversation, and right now nothing tells you
which of its sentences are legal." Then continue unchanged from 0:15.

**If the room is technical.** Swap slide 5 for a longer version of the
isolation boundary point and use the deck at
[../demo-day/deck.html](../demo-day/deck.html) slide 3 instead, which draws the
boundary properly. Everything else holds. See
[SCRIPT-TECHNICAL-AUDIENCE.md](SCRIPT-TECHNICAL-AUDIENCE.md).

**If the room is commercial.** Drop slide 5 entirely, which buys you 30
seconds, and spend it on what a compliance review costs today. See
[SCRIPT-BUSINESS-AUDIENCE.md](SCRIPT-BUSINESS-AUDIENCE.md).

**If you cannot run anything live.** Cut the rig block at 0:35 to 1:00 and open
on the bench instead. You gain 25 seconds; spend it on the case file. The
argument does not depend on the run being live, only on the evidence being
real, and every stored assessment is chain verified.

## What never changes

The triage sentence. In every variant of every length: this is a triage layer
that routes to human review, not a release gate. Three independent
measurements say so.
